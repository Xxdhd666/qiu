# 球（未完成版）

> ⚠️ 未完成版：这个项目还在打磨中，尚未达到完美标准，当前版本仅供试用和参考，后续会持续更新。

QuotaFloat 悬浮球项目专用仓库。

目标：做出完美的悬浮球程序。

## 完美标准

- 外形与材质
- 信息排版
- 面板设计
- 拖拽贴边、鼠标悬停动画
- 交互反馈
- 尺寸把控
- 稳定、占用小、不打扰
- 信息按天汇总等

## 规矩

- 为这个项目做活，只用 Gemini 和 Gemini 4（Argon）两个池子，Claude 池和 Codex 池留给用户自己用。
- 成果在微信上汇报，可以配图。
- 不恢复手动填写；仪表盘 620×720、无滚动条；悬浮球贴边自动收起、托盘后台运行。
- 数据来源：Codex 走 app-server 实时查询，Antigravity 走 agy /usage 自动采集，每 5 分钟刷新。

## 本地构建

```bash
npm install
npm run check
npm run pack
```

解压 `win-unpacked`，双击 `QuotaFloat.exe`，旧版先从托盘退出。
